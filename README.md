# no-round-discord-ui

A simple Discord theme that removes the rounded corners from Discord's UI, giving it a sharper, more square/flat look.

## Features
- Removes rounded corners on almost all UI elements
- Cleaner, more angular appearance
- Lightweight and minimal

## Installation

1. Install a custom Discord client like **Vencord** or **BetterDiscord**
2. Download the theme file (`noroundui.theme.css`)
3. Place it in your themes folder
4. Enable the theme in your client settings
